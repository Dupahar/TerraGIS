# TerraGIS Store Listing (English - United States)

## Description
TerraGIS is a modern desktop GIS application for professional spatial workflows on Windows.

It is designed for teams who need practical mapping and analysis tools without heavy infrastructure. TerraGIS supports core vector and raster workflows, map interaction, editing, export, and AI-assisted analysis integration.

Use TerraGIS to load and work with common geospatial data formats, organize layers, run day-to-day analysis tasks, and produce export-ready outputs for reporting and operations.

### Core capabilities
- Vector support for Shapefile, GeoPackage, and GeoJSON
- Raster support for GeoTIFF, ASC, and IMG
- Layer management with visibility controls, reorder, rename, grouping, and opacity
- Basemap switching with reliability hardening and alignment improvements
- Spatial analysis operations such as buffer, intersection, clip, dissolve, and reprojection
- Export workflows for vector outputs and layout exports (PDF, PNG, JPEG)
- Session persistence for layer state and project context
- AI-assisted processing pipeline integration through external service orchestration

TerraGIS private beta focuses on workflow reliability, packaging quality, and submission readiness for controlled pilot users.
